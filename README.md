# PlaywrightProject

This is a Playwright project for end-to-end testing.

## Getting Started

1. Install dependencies: `npm install`

2. Install browsers: `npx playwright install`

3. Run tests: `npm test`

4. Run tests in headed mode: `npm run test:headed`

## Test Structure

- `tests/` - Test files
- `playwright.config.ts` - Playwright configuration

## CI/CD

GitHub Actions workflow is set up to run tests on push and pull requests.
